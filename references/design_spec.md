# 红黑科技风 PPT 设计规范

> 基于"无人机时代"模板（22页）精确提取的设计数据

## 1. 基本参数

| 参数 | 值 |
|------|-----|
| 幻灯片尺寸 | 33.87 × 19.05 cm（16:9 宽屏） |
| 英寸尺寸 | 13.333 × 7.5 inch |
| 总页数（模板） | 22 页 |
| 主背景色 | 深灰/黑 (#1A1A1A) |
| 强调色 | 红色 #CA3B41 |

## 2. 字体规范

### 2.1 主字体
- **字体名称**: 字魂59号-创粗黑
- **备选字体**: 微软雅黑（当主字体不可用时）
- **使用范围**: 所有文字（标题、正文、数据、标签）

### 2.2 字号体系

| 用途 | 字号 | 加粗 | 颜色 | 出现位置 |
|------|------|------|------|----------|
| 封面主标题 | 60pt | 是 | 白色 | 封面页 |
| 章节大标题 | 44pt | 是 | 白色 | 章节过渡页 ENTER TITLE |
| 章节编号 | 36pt | 否 | 白色 | 章节过渡页 PART 01. |
| 目录标题 | 36pt | 是 | 红色 #CA3B41 | 目录页 Contents |
| 结尾文字 | 36pt | 是 | 白色 | 结尾页 THANK YOU |
| 页面标题 | 24pt | 是 | 白色 | 内容页左上角标题栏 |
| 卡片标题 | 16pt | 是 | 白色 | 三栏卡片红色标签 |
| 正文 | 14pt | 否 | 浅灰 #CCCCCC | 所有正文内容 |
| 数据数字 | 28pt | 是 | 白色 | 数据圆环内数字 |
| 数据标签 | 12pt | 否 | 浅灰 | 数据圆环下方标签 |

## 3. 配色方案

### 3.1 核心色板

| 颜色名称 | HEX | RGB | 用途 |
|----------|-----|-----|------|
| 强调红 | #CA3B41 | (202, 59, 65) | 标题强调、标签条、数据标记、色块 |
| 深色背景 | #1A1A1A | (26, 26, 26) | 页面主背景 |
| 纯白 | #FFFFFF | (255, 255, 255) | 标题文字、重要数据 |
| 浅灰 | #CCCCCC | (204, 204, 204) | 正文文字 |
| 中灰 | #888888 | (136, 136, 136) | 次要文字、装饰 |

### 3.2 用色原则
- **深色背景 + 白色文字** 为基础组合，确保高对比度可读性
- **红色** 仅用于强调：标题装饰条、卡片标签、数据标记、关键色块
- 红色面积控制在页面 10%-20%，避免过度使用
- 图片作为主要视觉元素时，文字叠加在图片暗部或使用半透明遮罩

### 4.2 页面类型清单

模板共包含以下 10 种页面类型：

#### 类型1: 封面页（第1页）
- 全屏背景图
- 居中大标题（艺术字效果）
- 左上角 "General Report Template" 装饰文字
- 无人机产品图作为视觉主体

#### 类型2: 目录页（第2页）
- 居中红色 "Contents" 标题（36pt）
- 垂直排列的目录条目
- 左右对称的红色弧形装饰图

#### 类型3: 章节过渡页（第3/8/13/18页）
- 左侧大图装饰（24.06 × 15.78 cm）
- 右侧文字区：
  - "PART 01." 编号（36pt，白色）
  - "ENTER TITLE" 大标题（44pt，加粗，白色）
- 文字区位置：左14.79cm，上8.23cm

#### 类型4: 标准内容页（多页）
- 左上角标题装饰组合（固定位置 3.17, 1.64）
- 红色竖条 + 白色标题文字
- 内容区域从 top=5.0cm 开始

#### 类型5: 三栏卡片页（第5页）
- 三个等宽卡片并排
- 每个卡片：上方图片 + 红色标签条 + 下方描述文字
- 卡片宽度约 6.52cm，间距均匀

#### 类型6: 图文混排页（第6页）
- 左侧图片区域
- 右侧红色实心矩形色块（15.31 × 7.93 cm，#CA3B41）
- 色块上叠加白色文字
- 色块位置：左18.53cm，上7.1cm

#### 类型7: 全图过渡页（第7/12/17页）
- 全屏背景图
- 顶部装饰小图
- 居中大标题（白色）
- 底部副标题/说明

#### 类型8: 数据圆环页（第11页）
- 红色同心圆标记（直径 3.16cm）
- 圆内白色数据数字
- 圆下方灰色数据标签
- 底部居中说明文字

#### 类型9: 左右对比页（第14/19页）
- 左侧红色强调标题 + 列表
- 右侧白色标题 + 多条内容
- 中央可放置产品图/装饰图

#### 类型10: 结尾页（第22页）
- 全屏背景图
- 居中 "THANK YOU"（36pt，加粗，白色）
- 与封面呼应的视觉元素

## 5. 视觉元素规范

### 5.1 装饰元素
- **红色弧形/流线图形**: 用于页面边缘装饰，营造动感
- **多边形几何体**: 散布在页面中，增加科技感
- **产品图/无人机图**: 作为各页面的视觉锚点
- **粒子/光点效果**: 用于全图过渡页底部

### 5.2 图片使用原则
- 图片是页面的主要视觉元素，占比通常 40%-60%
- 产品图采用 PNG 透明背景，可灵活叠加
- 背景图使用全屏覆盖，文字叠加在暗部区域
- 图片风格统一：科技感、暗色调、红色点缀

## 6. 文案格式规范

### 6.1 标题格式
- 章节编号格式: `PART 01.`（大写英文 + 两位数字 + 句点）
- 页面标题: 简洁有力，不超过 10 个汉字
- 封面标题: 可使用艺术字/特殊排版效果

### 6.2 正文格式
- 正文使用 14pt，行间距 1.2-1.5 倍
- 段落之间空 12pt
- 项目符号使用 "▸" 或红色小圆点
- 英文使用与中文相同的字体（字魂59号-创粗黑）

### 6.3 数据格式
- 数据数字突出显示（28pt 加粗）
- 单位/标签使用小字号（12pt 灰色）
- 百分比/数值可放置在红色圆环内
